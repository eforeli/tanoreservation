# TANO 訂位引擎｜分配演算法與測試案例
版本 v1.4 — 2026-11-14

## 1. 重要設計原則
固定桌容量和額外椅共享資源要一起檢查，預約起始時間相同不等於占用重疊；必須檢查完整區間。時間區間建議用半開區間 `[start, end)`，以免緊接不重疊被錯判。

## 2. 查詢可用時段（偽程式）
```
for slot in eligibleSlots(date, businessHours, latestSeating, interval=30min):
  if !withinBookingWindow(slot) or tooCloseToNow(slot): continue
  if arrivalsAt(slot) >= maxArrivalsPerSlot: continue

  for table in rankCandidatesByFit(partySize):
    if partySize > table.maxCapacity: continue
    if blocked(table, [slot, slot + 110min)): continue
    if activeReservationOverlap(table, [slot, slot + 110min)): continue

    chairsRequired = max(0, partySize - table.baseCapacity)
    if chairsRequired > 0:
      if maxConcurrentExtraChairs(
          proposed=[slot, slot + 90min),
          existingReservations
        ) + chairsRequired > extraChairsTotal: continue

    mark slot available (do not expose table to client)
    break
```

**注意** 上述 `maxConcurrentExtraChairs` 表示把新訂位椅子需求加到整段時間重疊的所有已占用椅子事件上，檢查任意時間點的峰值，非單純查開始時刻。可選用較保守的 110 分鐘椅子占用設定，以符合現場換桌移椅速度。

## 3. 最終訂位建立
使用單一資料庫交易：驗證入參 → 取得當日庫存鎖 → 讀取即時狀態 → 嘗試桌位候選排序 → 檢查桌、鎖桌、椅子、廚房新入席上限 → 新增訂位與分桌 → commit。若無合法解，回傳「該時段已滿，請重新選擇」。

同樣地，管理員修改應在 transaction 中檢查更新後全部衝突，若失敗 rollback，保留原訂位。取消狀態更新與庫存釋放需在同一 transaction 中完成。

## 4. 候選桌位排序策略
- 1–2 人：優先 A2、A1、A3，其次 A4、A5；A1/A3 和 A2 可根據未來預約保留度排序。
- 3 人：優先可用的 A4/A5（不加椅），否則 A1/A3 加椅；可再加入「保留四人桌」的營運權重，非固定不變。
- 4 人：A4/A5。
- 5 人：A4/A5 + 1 張額外椅。
- 6 人以上：不提供線上訂位。

候選桌不只考慮當下，也可考慮今日未來訂位、餐桌鎖定、加椅需求，避免不必要的可售座位浪費。第一版先用決定性規則排序，不需複雜最佳化求解器。

## 5. 驗收案例（節錄）
| 情況 | 預期 |
|---|---|
| A4 17:00 訂 5 人（+1 椅）；A1 17:30 訂 3 人（+1 椅） | 允許，只要個別桌位可用 |
| 上述兩組都在用餐中，A5 18:00 欲訂 5 人（再 +1 椅） | 不允許；即使 A5 空桌也沒有額外椅 |
| A4 17:00 訂 5 人 | A4 18:30 不可預約，19:00 可預約（沒有其他衝突時） |
| 鎖 A2 17:00–20:00 | 新訂位不可被配到 A2；仍可選其他桌 |
| 鎖桌覆蓋已有 A2 18:00 訂位 | 顯示衝突、保留訂位，需人工處理 |
| 管理員取消 A4 17:00 5 人 | 釋出 A4 和額外椅，立即重新計算 |
| 兩名客人同時搶最後可用的 A5 | 最多成功一筆，不可重複訂位 |
| 週日、週一或已封閉日期 | 不提供可用時段 |
| 6 人線上選人數 | 導向聯絡餐廳，不直接建立 |

## 6. 容易忽略的邊界
- 原訂位取消後被修改不能意外復活；可用狀態機限定合法轉移。
- 20 分鐘緩衝時間跨過營業結束的政策需確認；晚間最晚入席應控制。
- 顧客可能提早抵達／延遲離席；管理後台應允許實際占用修正與人工封鎖。
- 已預約 5 人後額外椅總數從 2 改為 1 時，顯示受影響訂位，不可無聲取消。
- 鎖桌備註只給管理員看，不公開給客人。
